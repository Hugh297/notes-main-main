Test Study Notes: HTML, CSS, and JavaScript

Review the key ideas, then practice reading and writing the examples. HTML gives content structure, CSS controls presentation, and JavaScript adds behavior.

Test tip: Know what each element or method does, when to use it, and how to recognize common mistakes such as a missing form label or an unclosed tag.

Lecture 04: HTML Lists and Tables

Ordered and unordered lists

An ordered list uses <ol> when sequence matters (steps, rankings); browsers usually number it. An unordered list uses <ul> when the order does not matter; browsers usually show bullets. Each list item goes in an <li>.

<ol>
  <li>Open the page</li>
  <li>Fill in the form</li>
</ol>

<ul>
  <li>Notebook</li>
  <li>Pencil</li>
</ul>

Description lists

<dl> groups terms and descriptions. <dt> is a term or name, and <dd> is its description or value.

<dl>
  <dt>HTML</dt>
  <dd>The language used to structure web content.</dd>
</dl>

Tables and their elements

Use an HTML table to present data with meaningful row-and-column relationships, not to lay out an entire page.

  • <table> contains the table.
  • <tr> creates a table row.
  • <th> marks a header cell (for a column or row).
  • <td> marks a regular data cell.
  • <caption> gives the table an accessible, visible title or summary.

colspan makes a cell span multiple columns; rowspan makes it span multiple rows. Semantic headers help people understand what data cells refer to, and help assistive technology and browsers interpret the table. Use scope="col" or scope="row" to clarify a header's direction.

<table>
  <caption>Quiz scores</caption>
  <tr>
    <th scope="col">Student</th>
    <th scope="col">Score</th>
  </tr>
  <tr>
    <th scope="row">Ari</th>
    <td>92</td>
  </tr>
  <tr>
    <td colspan="2">One student shown</td>
  </tr>
</table>

Lecture 05: Multimedia and Embedded Content

Images and responsive image choices

Use <img> to embed an image. Give it a useful alt description when it conveys information; use alt="" when it is purely decorative.

<img src="garden.jpg" alt="Sunflowers growing in a garden" loading="lazy">

<picture> wraps one or more <source> choices and a fallback <img>. The browser selects a suitable image based on conditions such as screen size or supported format. A plain <img> displays one image; <picture> lets you art-direct or offer alternate formats.

<picture>
  <source media="(min-width: 800px)" srcset="wide.jpg">
  <img src="small.jpg" alt="A mountain at sunrise">
</picture>

Audio, video, sources, and tracks

<audio> embeds sound; <video> embeds video. Add controls to provide playback controls. A <source> inside a media element offers a file and MIME type; the browser tries supported choices in order. A <source> inside <picture> provides an image choice.

<track> supplies timed text such as subtitles, captions, descriptions, or chapters for audio/video. Captions include relevant non-speech sounds; subtitles commonly translate spoken dialogue. Alternative text and captions make content more accessible to people who cannot see or hear it, and text alternatives also help when media fails to load.

<video controls>
  <source src="lesson.mp4" type="video/mp4">
  <track kind="captions" src="lesson-en.vtt"
         srclang="en" label="English">
  Your browser does not support video.
</video>

Lazy loading

loading="lazy" asks the browser to defer loading an image or iframe until it is near the visible part of the page. This can save data and speed up initial loading. Avoid lazy-loading important above-the-fold images, such as a page's main hero image.

Lecture 06: Hyperlinks and Local Domains

Links and URLs

A hyperlink connects a page or resource to another destination. The <a> (anchor) element creates the link, and its href attribute gives the destination.

An absolute URL includes the full address, such as https://example.com/about.html. A relative URL is resolved from the current page or site location, such as about.html or ../images/photo.jpg. To link to another page in the same project, use its relative path.

<a href="about.html">About this site</a>
<a href="#contact">Jump to contact section</a>

<h2 id="contact">Contact</h2>

<a href="mailto:hello@example.com">Email us</a>

A fragment such as #contact jumps to the element whose id is contact. mailto: opens the user's configured email application.

Opening external links safely

target="_blank" requests that the destination open in a new tab or window. For an external link opened this way, rel="noopener noreferrer" prevents the new page from controlling the originating page through window.opener; noreferrer also withholds referrer information.

<a href="https://example.com"
   target="_blank" rel="noopener noreferrer">
  Visit Example
</a>

Lecture 07: HTML Forms

Form elements and attributes

An HTML form collects user input for processing or submission. <form> groups the controls; <input> creates many kinds of controls; <label> names a control; <textarea> accepts multi-line text; and <button> creates a button.

action specifies where the form submits. method specifies how it submits:

  • GET places form data in the URL query string. Use it for retrieval/search when appropriate; URLs may be bookmarked and shared, so do not use it for secrets.
  • POST sends form data in the request body. It is commonly used to submit or change data. POST alone does not encrypt data; HTTPS is needed for transport security.

Common input types include text, password, email, number, checkbox, radio, date, file, and submit.

  • id uniquely identifies an element in the page and can connect it to a label.
  • name is the key used for that control's submitted data.
  • value is the control's current or submitted value.

required makes a control need a value before a browser will submit the form. Form validation checks that input meets rules, such as being required or matching an email format; client-side validation improves usability but does not replace server-side validation.

Labels, dropdowns, and a complete example

Connect a label to an input by making the label's for value exactly match the input's id. Clicking the label then focuses or activates its control.

<form action="/signup" method="post">
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>

  <label for="message">Message</label>
  <textarea id="message" name="message"></textarea>

  <label for="topic">Topic</label>
  <select id="topic" name="topic">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
  </select>

  <button type="submit">Sign up</button>
</form>

A dropdown uses <select> to contain <option> choices. Use a button's type deliberately: submit submits a form, while button does not submit by default.

Lecture 08: CSS Fundamentals

What CSS does and where to write it

CSS (Cascading Style Sheets) describes how HTML content looks and is laid out. The three ways to write CSS are:

  • Inline: a style attribute on one element. Convenient for a one-off, but hard to reuse and maintain.
  • Internal: rules inside a <style> element, usually in the document's <head>.
  • External: rules in a separate .css file, linked from HTML. Best for reuse and keeping content separate from presentation.
<!-- In the HTML head -->
<link rel="stylesheet" href="styles.css">

<!-- Example rules in styles.css -->
p { color: #333; }
.notice { background-color: #fff3cd; }
#main-title { font-size: 2rem; }

Selectors, cascade, specificity, and inheritance

  • An element selector, such as p, selects all elements of that type.
  • A class selector, such as .notice, selects elements with that class; classes can be reused.
  • An ID selector, such as #main-title, selects the element with that ID; IDs should be unique in a page.

The cascade decides which declarations apply when rules overlap. It considers origin and importance, selector specificity, and then source order when the earlier factors tie. Specificity is the selector's priority: IDs outweigh classes/attributes, which outweigh element selectors. Prefer simple selectors and avoid relying on !important.

Inheritance means some properties (often text-related properties like color and font-family) pass from a parent to descendants unless overridden. Many box and layout properties do not inherit by default.

Box model and spacing

The CSS box model describes an element as content → padding → border → margin. Padding is space inside the border, around content; margin is space outside the border, separating the element from others. With box-sizing: border-box, declared width and height include padding and border.

Need to styleCommon properties
Textcolor, font-family, font-size, font-weight, text-align, line-height
Backgroundbackground-color, background-image
Borderborder, border-width, border-color, border-radius
Spacingmargin, padding, gap
.card {
  margin: 16px;
  padding: 20px;
  border: 1px solid #ccd5e0;
  background-color: white;
  color: #203047;
}

Lecture 10: Respond to Events

Event-driven programming and listeners

Event-driven programming runs code in response to actions or occurrences, such as a click or page load. An event listener waits for a particular event on an element. addEventListener() registers a callback function to run when that event happens.

const button = document.querySelector("#change-button");
const message = document.querySelector("#message");

button.addEventListener("click", function () {
  message.textContent = "Button clicked!";
});

Prefer addEventListener() to inline onclick="...": it keeps behavior out of HTML, allows multiple listeners, and supports options such as capturing and one-time listeners. In a regular function used as a listener, this refers to the element the listener is attached to (the event's currentTarget). event.target is the element where the event originated, which may be a child. Arrow functions do not get their own this; they use the surrounding value.

Common events and event control

EventWhen it occurs
inputAs a form control's value changes, often while the user types.
clickWhen an element is activated with a click.
dblclickWhen an element is double-clicked.
mouseoverWhen a pointer enters an element or one of its descendants; it bubbles.
mouseenterWhen a pointer enters an element; it does not bubble and does not fire again just for entering its children.

event.preventDefault() cancels a browser's default action, such as navigating to a link or submitting a form. event.stopPropagation() prevents that event from continuing through the propagation path; it does not cancel the default action.

Event bubbling is the propagation phase where an event travels from its originating element up through its ancestors. Event delegation uses this behavior: put one listener on a parent and check event.target (or closest()) to handle matching child interactions. This is useful for many or dynamically added children.

Page loading events

DOMContentLoaded fires when the HTML has been parsed and the DOM is ready; it does not wait for all images and other dependent resources. The window load event waits until the page and its dependent resources have loaded.

document.addEventListener("DOMContentLoaded", function () {
  const button = document.querySelector("#change-button");
  button.addEventListener("click", function () {
    document.body.classList.toggle("highlight");
  });
});

Lecture 11: Produce Dynamic Content

Arrays, objects, and loops

Dynamic content is content created or updated by a program while a page is running. An array stores an ordered list of values; an object stores related values as key/property pairs. Access an object property with dot notation (person.name) or brackets (person["name"]). Access an object inside an array by index, then property: people[0].name.

const people = [
  { name: "Ari", score: 92 },
  { name: "Sam", score: 85 }
];

for (let i = 0; i < people.length; i++) {
  console.log(people[i].name);
}

for (const person of people) {
  console.log(person.score);
}

people.forEach(function (person) {
  console.log(person.name);
});

A traditional for loop gives you an index and control over the loop. for...of visits each iterable value and can be stopped with break. forEach() calls a function for each array item but does not provide the same ability to break out early.

Templates, elements, and array methods

A template literal uses backticks and can span lines. ${expression} inserts an expression's value into it.

Create elements with document.createElement(), set their text or attributes, and append them with append() or appendChild(). Use textContent for plain text; do not put untrusted data into innerHTML.

const list = document.querySelector("#people-list");
people.forEach(function (person) {
  const item = document.createElement("li");
  item.textContent = `${person.name}: ${person.score}`;
  list.append(item);
});

map() transforms each array item and returns a new array of results. filter() returns a new array containing only items that pass a condition. For numeric sorting, sort() needs a comparison function; by default it sorts values as strings and changes the original array.

const scores = [8, 100, 25];
scores.sort((a, b) => a - b); // ascending: [8, 25, 100]
scores.sort((a, b) => b - a); // descending

Timers and browser storage

setTimeout(callback, delay) schedules a callback once after a delay in milliseconds. setInterval(callback, delay) schedules it repeatedly. clearInterval(id) stops a repeating timer using the ID returned by setInterval().

let seconds = 0;
const timerId = setInterval(function () {
  seconds += 1;
  document.querySelector("#clock").textContent = seconds;
  if (seconds === 10) clearInterval(timerId);
}, 1000);

localStorage stores string data in the browser for the current site origin across page visits. It is synchronous and should not be used for sensitive data. Use JSON.stringify() to turn an object into a JSON string before saving, and JSON.parse() to turn the saved JSON string back into a value.

const settings = { theme: "dark", fontSize: 16 };
localStorage.setItem("settings", JSON.stringify(settings));

const saved = localStorage.getItem("settings");
if (saved !== null) {
  const restoredSettings = JSON.parse(saved);
  console.log(restoredSettings.theme);
}

Lecture 12: Generate Effects

Shadows and gradients

box-shadow adds a shadow around an element's box. text-shadow adds a shadow behind text glyphs. Both can take horizontal and vertical offsets, blur, and color; box-shadow can also have spread and an optional inset.

A linear gradient blends along a straight line, a radial gradient spreads outward from a center point, and a conic gradient sweeps around a center. Color stops define which colors appear and where in the gradient they transition.

.card {
  box-shadow: 0 4px 12px rgb(0 0 0 / 15%);
  background: linear-gradient(90deg, #dceeff 0%, #fff 100%);
}

h1 {
  text-shadow: 1px 2px 3px rgb(0 0 0 / 20%);
}

Visibility and transitions

  • opacity: 0 makes an element transparent but it still occupies layout space and can still receive interaction unless separately disabled.
  • visibility: hidden hides the element while preserving its layout space; it is generally not interactive while hidden.
  • display: none removes the element from layout and it is not shown.

A CSS transition animates a property as it changes value. transition-property names the property, transition-duration sets how long it takes, transition-timing-function sets the rate curve, and transition-delay sets how long before it starts.

  • linear: constant speed.
  • ease: starts and finishes more gently (the default).
  • ease-in: starts slowly and speeds up.
  • ease-out: starts quickly and slows down.
  • ease-in-out: starts and finishes slowly.
.button {
  background-color: #2459a6;
  transition: background-color 180ms ease-in-out;
}

.button:hover {
  background-color: #173d78;
}

Transforms and design purpose

translate() moves an element, rotate() turns it, scale() changes its size, and skew() slants it. transform-origin chooses the point around which a rotation, scale, or skew occurs. Transforms usually do not change the normal document flow.

.tile {
  transform-origin: center;
  transition: transform 180ms ease;
}

.tile:hover {
  transform: translateY(-3px) scale(1.02);
}

Subtle shadows can suggest depth and help separate important components. Short, restrained transitions clarify that an interaction happened and make interface changes feel smoother. Keep motion purposeful and avoid effects that distract or make content hard to use.

Practical Coding Review

For coding questions, first identify the HTML element, CSS selector, or event involved. Then check that attributes, IDs, braces, parentheses, and closing tags match.

One compact practice example

This example combines a form, event handling, dynamic elements, an array of objects, a timer, and local storage. It uses textContent so submitted text is treated as text, not HTML.

<form id="task-form">
  <label for="task-input">New task</label>
  <input id="task-input" name="task" required>
  <button type="submit">Add task</button>
</form>
<ul id="task-list"></ul>
<p>Seconds on page: <span id="seconds">0</span></p>

<script>
  const form = document.querySelector("#task-form");
  const input = document.querySelector("#task-input");
  const list = document.querySelector("#task-list");
  const tasks = JSON.parse(localStorage.getItem("tasks") || "[]");

  function renderTasks() {
    list.replaceChildren();
    for (const task of tasks) {
      const item = document.createElement("li");
      item.textContent = task.text;
      list.append(item);
    }
  }

  renderTasks();

  form.addEventListener("submit", function (event) {
    event.preventDefault();
    tasks.push({ text: input.value });
    localStorage.setItem("tasks", JSON.stringify(tasks));
    renderTasks();
    form.reset();
  });

  let seconds = 0;
  setInterval(function () {
    seconds += 1;
    document.querySelector("#seconds").textContent = seconds;
  }, 1000);
</script>

Here, preventDefault() stops the browser's normal form navigation. The submit callback saves the new task, redraws the list, and clears the input. The interval updates the page once per second.

Quick self-check

  1. Use <ol> for steps in sequence and <ul> for a collection without required order.
  2. Use <th scope="col"> or <th scope="row"> for table headers.
  3. Give informative images meaningful alternative text; add captions for video when needed.
  4. Connect every form label to the matching control ID; remember that submitted fields need a name.
  5. Use addEventListener() for behavior, and use event.preventDefault() only when the default action should be canceled.
  6. Use map() to transform an array, filter() to select items, and a numeric comparator to sort numbers.
  7. Serialize objects with JSON.stringify() before saving them in local storage.
  8. Use margin outside an element's border and padding inside it.

Good luck on your test! Practice writing the examples from memory, then explain why each element, attribute, selector, or method is used.
