Positioning, Alignment, and Overflow

Positioning

Static positioning is the default. Relative positioning offsets an element from its normal position.

.box {
    position: static;
}

.box {
    position: relative;
    top: 20px;
    left: 30px;
}

Absolute positioning places an element relative to its nearest positioned ancestor.

.box {
    position: absolute;
    top: 0;
    right: 0;
}

Fixed positioning is relative to the viewport; sticky positioning sticks after reaching its offset.

.nav {
    position: fixed;
    top: 0;
    width: 100%;
}

.header {
    position: sticky;
    top: 0;
}

Use z-index to control stacking order of positioned elements.

.modal {
    z-index: 100;
}

.overlay {
    z-index: 99;
}

Alignment

Center a fixed-width block with auto margins, center inline content with text alignment, or center items in a grid.

.box {
    margin: 0 auto;
    width: 300px;
}

.parent {
    text-align: center;
}

.parent {
    display: grid;
    place-items: center;
}

Overflow

These are alternative overflow settings; use the one that fits the desired behavior.

.container {
    overflow: hidden; /* Clip */
    overflow: scroll; /* Always scrollbars */
    overflow: auto; /* Scroll when needed */
}
